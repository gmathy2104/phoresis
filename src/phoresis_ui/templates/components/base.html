Alpine 3 cdn-build queueMicrotask()'s start() at the end of its module, which fires `alpine:init` at the next microtask checkpoint -- which happens BETWEEN deferred scripts. So if alpine.js is loaded BEFORE alpine-init.js (both with defer), alpine:init fires before the listener is registered, and EVERY $store.* on the page comes back undefined. Per Alpine's own docs example, the init code must run BEFORE Alpine's bundle. {% endcomment %} {# HTMX 2 + Alpine.js 3 -- self-hosted via WhiteNoise.
