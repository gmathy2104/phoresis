Normalization Methods

Lane Total

Each band is expressed as a percentage of its lane's total area.

  • Each lane sums to ~100%
  • Best for comparing bands within the same lane
  • Default method for most analyses
Band % = (Band Area / Lane Total) × 100

Gel Total

Each band is expressed as a percentage of the entire gel's total area.

  • Entire gel sums to 100%
  • Best for comparing bands across different lanes
  • Useful for relative quantification between samples
Band % = (Band Area / Gel Total) × 100

Loading Control

Each band is expressed relative to MW Reference bands in the same lane.

  • Values can exceed 100%
  • Requires bands marked as "MW Reference" type
  • Compensates for unequal sample loading
  • Falls back to Lane Total if no reference bands
Band % = (Band Area / Reference Area) × 100

How Densitometry Works

Densitometry quantifies band intensities from gel images in four steps. Each lane is analyzed independently to produce an electropherogram and per-band measurements.

1

Profile Extraction

For each lane, a 1D intensity profile is built from the 2D gel image. At every vertical position (Y row), pixel intensities are averaged across the lane width.

Lane (2D)                  Profile (1D)

 ┌─────────┐               │
 │░░███░░░░│  ─── avg ───► │    ╭──╮
 │░░███░░░░│               │    │  │
 │░░░░░░░░░│               │ ───┘  └───
 │░████████│  ─── avg ───► │  ╭──────╮
 │░████████│               │  │      │
 │░░░░░░░░░│               │──┘      └──
 └─────────┘               │
  ◄──50%──►                Intensity →
  (center)

By default, only the center 50% of the lane width is used (configurable via profile_width_percent). This avoids edge artifacts and noise from lane boundaries. For polygon-shaped lanes, margins are recalculated at each row.

2

Signal Processing

The raw profile is cleaned up through two operations:

  • Savitzky-Golay smoothing — reduces high-frequency noise while preserving peak shape, height, and width (window size: 11 points)
  • Background subtraction — removes the baseline signal using the rolling ball algorithm (simulates a ball rolling under the curve)
  Raw             Smoothed          Background-subtracted

  ╭╮ ╭╮           ╭╮  ╭╮                ╭╮  ╭╮
 ╭╯╰╮╯╰╮╭─      ╭╯╰──╯╰╮╭─            ╭╯╰──╯╰╮
╭╯~~~~╰───╯    ╭╯~~~~~~~~╰╯         ───╯       ╰───
~~~~~~~~       ─────────────         ───────────────
               (noise removed)       (baseline flat)

The result is a clean electropherogram where each peak corresponds to a protein band.

3

Peak Integration

Each annotated band is matched to its region on the electropherogram. A Gaussian curve is fitted to the peak, and the area under the curve is computed as the band's intensity.

     ╭──╮
    ╱ ·· ╲          Area = ∫ G(x) dx
   ╱ ·  · ╲
  ╱ ·    · ╲        G(x) = A · exp(-(x-μ)² / 2σ²)
─╱··      ··╲───
                    R² = goodness of fit (closer to 1 = better)

The R² value shown in the measurements table indicates how well the Gaussian curve fits the actual peak shape. Values above 0.95 indicate a clean, well-resolved band.

4

Normalization & Purity

Band areas are converted to relative percentages using the selected normalization method:

  • Lane Total — each band as % of its lane total (each lane sums to 100%)
  • Gel Total — each band as % of the entire gel area
  • Loading Control — relative to MW Reference bands
Purity (%) = POI Area / (POI Area + OTHER Area) × 100

Note: MW Reference bands are excluded from purity calculations.

The Protein of Interest (POI) band is the target protein you are measuring. All other bands are impurities. MW Reference bands (from ladder lanes) serve only as molecular weight markers.
