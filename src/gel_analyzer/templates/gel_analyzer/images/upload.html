{% comment %} Drop-zone notes: - `dragover` (which fires constantly while a file hovers) keeps `active` true. `dragleave` schedules a 60 ms revert; if any dragenter/dragover fires before that timer expires, we cancel it. This bulletproof pattern eliminates the flicker that the naive enter/leave-toggle (and even a depth counter) suffer from when the browser fires phantom leaves mid-drag. - The whole dropzone is clickable via `@click="pickFiles()"`. Inner content has `pointer-events-none` so clicks bubble up to the wrapper instead of being eaten by the SVG. - File assignment via DataTransfer.items.add(...) -> input.files (the well-supported way) instead of direct `input.files = ...` which is flaky on some Edge versions. - `fileName` reactive field shows visual confirmation of the attached file. {% endcomment %}
