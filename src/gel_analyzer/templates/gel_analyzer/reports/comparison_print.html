Materials & Methods

Densitometry

Quantitative band analysis is performed using Gaussian peak fitting with rolling ball background subtraction. Each band's intensity profile is extracted perpendicular to the migration direction and fitted to a Gaussian function using scipy's curve_fit algorithm with robust least-squares optimization.

Calibration

Molecular weight estimation employs log-linear regression of known MW ladder standards against relative migration (Rf) values. Calibration curves follow the equation log₁₀(MW) = slope × Rf + intercept.

Purity

Purity (%) = (POI Area / Total Lane Area) × 100. Background-corrected areas are used to ensure accurate quantification.
